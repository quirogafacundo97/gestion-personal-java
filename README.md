# Sistema de Gestión de Personal - Java

Proyecto orientado a objetos desarrollado en Java para gestionar personal de una empresa.

## Conceptos aplicados

- Herencia
- Abstracción
- Polimorfismo
- Encapsulamiento
- Composición
- Sobrescritura de métodos
- Métodos abstractos

## Estructura

- Personal (abstracta)
- Empleado (abstracta)
  - Secretario
  - Vendedor
- Pasante
- CocheEmpresa

## Funcionalidades

- Gestión de personal
- Incremento de salarios
- Supervisión de empleados
- Vehículos empresariales
- Conteo de tipos de personal mediante polimorfismo
